# MasjidClock

ESP32 يبث شبكة واي فاي خاصة بالمسجد (**Masjid-Time**)، وتتصل بها شاشات المسجد (تلفزيونات AzanTV)، وتأخذ منه الوقت (NTP) بدون إنترنت.

## مصادر الوقت (الأفضل أولاً)
1. الإنترنت، إذا أُضيف راوتر في الإعدادات (اختياري).
2. موديول DS3231 ببطارية (اختياري)، يحفظ الوقت عند انقطاع الكهرباء.
3. هاتف يتصل بالشبكة: إذا كان الوقت غير مضبوط تفتح صفحة تلقائياً وترسل وقت الهاتف.
   إذا كان الوقت مضبوطاً، لا يتغير إلا بالرمز (الافتراضي `1234`)، حتى لا تغيّره هواتف المصلين.

ضوء اللوحة: ثابت = الوقت مضبوط، يومض = ينتظر هاتفاً يضبطه.

## التوصيل (DS3231)
| DS3231 | ESP32 |
|---|---|
| GND | GND |
| VCC | 3V3 (ليس 5V) |
| SDA | GPIO21 |
| SCL | GPIO22 |

## الرفع
```
pio run -t upload
```

## إعداد الشاشات
1. اتصل من التلفزيون بشبكة **Masjid-Time**.
2. وجّهه إلى الساعة:
```
adb shell settings put global ntp_server 192.168.4.1
```
للتراجع: `adb shell settings delete global ntp_server`

## الإعدادات
من أي هاتف متصل بالشبكة افتح http://192.168.4.1، ثم "الإعدادات". يمكن تغيير: اسم الشبكة، وكلمة مرورها، والراوتر، والرمز.
تتسع الشبكة لـ 8 أجهزة في نفس الوقت.
